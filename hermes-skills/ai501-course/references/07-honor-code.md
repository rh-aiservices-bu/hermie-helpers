# Module 7 — The Honor Code

Primary sources: `docs/7-honor-code/`. Related repositories: `backend`, GitOps,
Helm charts, and the Llama Stack configuration used by Canopy.

Use this module for guardrail concepts, NeMo Guardrails, Llama Stack shields,
prompt-injection testing, Spikee, automated checks, and Canopy integration.

Troubleshooting focus:

- Locate failure in guardrail service deployment, Llama Stack provider/shield
  configuration, backend shield selection, or automated test expectations.
- Distinguish a guardrail rejecting content as designed from service failure.
- Do not suggest disabling guardrails merely to pass an exercise.
- Treat security-test payloads as lab evidence and keep commands aligned with the
  exercise.
