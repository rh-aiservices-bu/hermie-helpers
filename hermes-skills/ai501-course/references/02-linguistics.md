# Module 2 — Linguistics

Primary sources: `docs/2-linguistics/`. Related repositories: `frontend`,
`backend`, and `experiments`.

Use this module for prompt engineering, prompt registry/versioning, GenAI
Playground behavior, and the first Canopy deployment and system-prompt changes.

Troubleshooting focus:

- Identify whether the problem is prompt content, prompt version selection, model
  behavior, frontend deployment, or backend configuration.
- For Canopy behavior, read `3-canopy-ai.md` before inspecting `frontend`.
- Verify that a prompt change reached the component and environment named by the
  exercise; do not assume saving a prompt automatically deploys it.
