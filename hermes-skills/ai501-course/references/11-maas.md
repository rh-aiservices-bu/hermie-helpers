# Module 11 — Supply and Demand 101

Primary sources: `docs/11-maas/`. Related repositories: `backend`, GitOps, Helm
charts, and the LiteMaaS deployment referenced by the exercise.

Use this module for MaaS concepts, LiteMaaS deployment, shared model endpoints,
API keys, usage tracking, Canopy integration, and Sealed Secrets.

Troubleshooting focus:

- Separate provider model availability, LiteMaaS deployment, authentication,
  routing, quota/usage recording, and Canopy configuration.
- Never ask the learner to paste an API key; use redacted evidence and status codes.
- Check whether a key is created, mounted/referenced, and accepted without exposing
  its value.
- Treat files marked WIP in course content as non-authoritative unless the active
  exercise links to them.
