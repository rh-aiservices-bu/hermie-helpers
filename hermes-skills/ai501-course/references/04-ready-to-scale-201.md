# Module 4 — Ready to Scale 201

Primary sources: `docs/4-ready-to-scale-201/`. Related repositories: `evals`,
`experiments`, `backend`, and GitOps/Helm repositories.

Use this module for MLflow tracing/evaluation, GuideLLM, Kubeflow Pipelines,
Tekton triggers, evaluation datasets, and promotion of prompt changes.

Troubleshooting focus:

- Distinguish evaluation definition, trace collection, pipeline compilation,
  pipeline execution, trigger delivery, and promotion failures.
- Ask for the failed task/component and its small relevant log section.
- Check dataset, prompt version, endpoint, credentials/configuration, and expected
  artifact location from the exercise before changing pipeline code.
