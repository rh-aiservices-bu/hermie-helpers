# Module 5 — The Library

Primary sources: `docs/5-grounded-ai/`. Related repositories: `backend`, `evals`,
`experiments`, GitOps, and Helm repositories.

Use this module for RAG, embeddings, Milvus, Docling, document ingestion,
Open GenAI Stack/Llama Stack integration, RAG evaluation, and end-to-end pipelines.

Troubleshooting focus:

- Locate failure in extraction, chunking, embedding, storage, retrieval,
  generation, evaluation, or orchestration.
- Confirm test/prod collection and endpoint names from the exercise rather than
  inventing them.
- For poor answers, inspect retrieval evidence before tuning generation prompts.
- For empty retrieval, check ingestion completion and collection contents before
  changing Canopy.
