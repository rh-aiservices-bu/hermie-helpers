# Module 6 — The AI Watcher

Primary sources: `docs/6-observability/`. Related repositories: `backend`,
`frontend`, `evals`, and deployment configuration.

Use this module for vLLM metrics, Prometheus, Grafana, Loki logging, OpenTelemetry,
MLflow tracing, feedback, A/B testing, and prompt optimization.

Troubleshooting focus:

- Metrics: distinguish emission, scraping, querying, and dashboard display.
- Logs: distinguish application output, collection, storage, and query labels.
- Traces: identify the emitting component, exporter configuration, destination,
  and request correlation.
- Feedback: verify capture, persistence, association with a trace, and evaluation
  consumption.
- Read the exact exercise before naming environment variables or endpoints.
