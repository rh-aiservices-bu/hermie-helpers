# Module 1 — The AI Orientation

Primary sources: `docs/1-the-ai-orientation/README.md` and exercises
`2a-model-mannerisms.md`, `2b-prompting-principles.md`, and
`2c-model-mechanics.md`.

Use this module for model behavior, non-determinism, hallucinations, memory,
prompt composition, tokens, context windows, inference, CPU/GPU behavior, model
cards, and resource requirements.

Troubleshooting focus:

- Separate expected model variability from infrastructure failure.
- Check the exact prompt, selected model, parameters, and expected learning point.
- Do not promise deterministic output unless the exercise fixes the relevant inputs.
- Consult `experiments` only when the exercise points to a notebook or model test.
