# Module 10 — The Fitness Program

Primary sources: `docs/10-model-optimization/`. Related repositories:
`experiments`, `evals`, `backend`, and deployment configuration.

Use this module for quantization, LLM-Compressor, model artifacts, perplexity and
benchmark evaluation, FP8 deployment, and updating Canopy to an optimized model.

Troubleshooting focus:

- Separate compression execution, artifact storage/registration, deployment,
  compatibility, quality evaluation, and Canopy configuration.
- Confirm hardware/runtime support for the selected format.
- Treat quality changes as measurements requiring the exercise's evaluation, not
  subjective proof from a single response.
- Test the optimized endpoint before debugging downstream Canopy behavior.
